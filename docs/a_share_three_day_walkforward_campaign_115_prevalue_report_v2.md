# Campaign115：一次性来源验收门禁

Campaign115 的 `limit_list_d` 一次性验收协议和 runner 已冻结。runner 只允许固定 2026-07-13、固定五字段、全市场事件表和最多一次供应商调用；普通 `plan` 零写入、零网络，真实 `run` 必须同时带有“当前账户已有 5000 积分”的人工确认与执行确认。任何权限、空响应、字段、类别、日期、重复、5000 行截断、公式或原子写入失败都会留下不含供应商原文和凭据的终止记录，并永久禁止换 Token、日期、字段或公式重试。

19 项适配器/runner 定向测试、Ruff 和 Black 均通过。真实零网络 plan 已验证协议、合同、适配器、日历、固定日期 4592 只点时可买股票、无旧结果、私有且被 Git 忽略的 `.env` 以及非空 Token；唯一未通过项是人工 5000 积分权限确认，故 `ready=false`、退出码 2，供应商调用数为 0。

这是必要的研究效率门禁：旧账户已在同一接口被 3000 积分权限拒绝，Token 存在或更换不能证明新账户已经具备 5000 积分，也不能通过试探接口来猜权限。当前 Campaign115 尚无来源行、候选值、比较值、日线或收益；141 个完整定义和 134 个数值比较器不变。Candidate49 仍是唯一前瞻候选，两本账本不变。
