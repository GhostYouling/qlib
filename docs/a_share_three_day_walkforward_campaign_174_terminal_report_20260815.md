# Campaign174 企业市场风险敞口与套期保值来源前沿值前终止

Campaign174 在不读取来源行、文档正文、敞口或套保数值、候选值、比较器、证券价格或收益的条件下，固定审查 7 条路线。外汇交易/折算敞口与套保、利率重定价与套保、商品输入/输出价格敞口与套保，以及衍生品指定/有效性/终止状态是 4 个不同的发行人市场风险管理状态；本地没有完整冻结其点时来源、首次公开与生效时间、风险与工具身份、币种/基准/商品/期限/单位、对冲指定与有效性、修订链和 2019–2023 全市场覆盖合同，因此只记为来源准入延期，不宣称因子无效。
