# A 股三日短线历史滚动研究：Campaign064

Campaign064 已在无收益唯一性门终止。因子覆盖和容量充足，与 94 个可数值比较的历史因子也全部满足独特性门；但预注册的第 95 项是 Campaign063 的零有效值终止因子，无法形成任何共同比较会话。按照冻结的“95 项全部通过”规则，Campaign064 必须拒绝，并且没有打开日线价格或未来收益。

## 冻结因子

- 名称：`intraday_range_weak_order_entropy_236t`
- 方向：越高越好
- 输入：每个股票日精确 240 个连续竞价 `high/low`，上午和下午各 120 根；不读 `open/close/volume/amount`，不跨午间或交易日。
- 信号：先计算 `x_i = ln(high_i/low_i)`。在两个半场内形成精确 236 个重叠三元组，对三个零容差两两比较结果归入 13 个传递弱序状态，再返回状态分布的 Shannon 熵除以 `ln(13)`。
- 取值范围：`[0,1]`。零振幅和精确相等都保留，不加 jitter、容差、填充、裁剪、winsorize、阈值、拟合或组合。

经济假设是：日内振幅相对次序越多样，短期价格状态可能包含更丰富、较少被单一波动形态支配的信息。此次研究没有检验收益预测力，因为候选在收益前的预注册比较门被拒绝。

## Campaign065 前置政策

Campaign064 的结果暴露出一个流程问题：若零有效值终止因子继续作为“全部必须通过”的数值相关性比较项，所有以后候选都会被机械拒绝。已经在任何 Campaign065 候选定义或读值前冻结一条统一政策：

- 完整历史特征/机制/失败库仍保留全部 96 个定义（原 95 项加 Campaign064），不得删除终止或失败因子。
- 数值相关性门只使用在旧冻结快照上至少有 100 个、每个至少 50 个有效名称会话的来源。
- Campaign063 保留为显式的非数值机制挑战，不算相关性通过，也不算未来候选相关性失败；它仍必须出现在机制重叠审计和报告中。
- Campaign064 有完整数值快照，因此作为 Campaign065 的最后一个数值比较项。未来数值比较项共 95 个，仍全部必须满足 50 名称、100 会话和绝对中位相关严格低于 0.8。
- 资格划分只使用不可变旧证据，不能根据 Campaign065 候选值、相关性或收益动态删项，也不能追溯救援 Campaign064。

当前上市快照会带来幸存者偏差。该结果是历史研究流程证据，不是纯净样本外证据，也不是投资建议。Campaign065 的离线概念筛选可以随时开始，不需要等待新增日线或 16:30；Candidate49 的同日前瞻工作流仍必须等待当日 16:30 后先运行 `plan`，且仅在 `ready=true`、退出码为 0 时才可执行 `run --confirm-run`。
