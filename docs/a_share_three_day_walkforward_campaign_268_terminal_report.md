# Campaign268：期权隐含偏度/期限结构来源值前终止

Campaign268 只重访 Campaign157 的 c157_04，并在任何期权合约行、期权价格、曲面值、候选值、比较器、证券价格或收益值打开之前完成有限来源审计。结论是来源合同终止，不是因子预测失败：当前授权与已审官方元数据无法同时证明覆盖 A 股合格分母的直接个股期权、点时合约及调整历史、收盘已知报价质量、隐含波动率输入和无存续偏差的 2019–2023 完整历史。

## 有限路线

共冻结 7 条路线：完整个股期权曲面、Tushare `opt_daily` 加 `opt_basic` 合成曲面、ETF 期权映射成分股、股指期权映射成分股、仅用收盘/结算价反解隐波、当前合约或产品名单历史回填，以及行权价/Delta/期限/流动性/子集/模型搜索。7 条全部值前拒绝，公式和方向保持空；没有选中因子、快照、适配器、来源请求、比较值、开发试验或 2024–2025 压力试验。

Tushare `opt_daily` 在 2000 积分级提供 OHLC、结算、成交量/额与持仓量，但没有买卖报价、隐含波动率、Greeks、标的现价、利率、股息/持有成本或合约调整版本。`opt_basic` 要求 5000 积分，超过当前 3000 积分边界，而且公开查询合同没有证明每日点时的历史修订档案。不能因为日线可取，就在缺少合约主数据与定价输入时从收盘或结算价任意反解隐波。

上交所本轮官方公告列出的 5 个期权标的全部为 ETF，深交所官方产品指南列出的 4 个也全部为 ETF；中金所股指期权的标的是沪深300、中证1000和上证50指数。它们属于篮子或市场共同状态，不是发行人直接观测。把同一 ETF/指数曲面赋给成分股，还需要点时成分权重、重叠规则和事前冻结的股票暴露交互，不能在看到结果后把共同状态重贴成个股因子。
