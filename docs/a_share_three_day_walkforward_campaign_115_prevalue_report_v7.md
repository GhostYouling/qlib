# Campaign115：2019–2023 开发源同步器已预建

Campaign115 仍停留在任何真实数据商取值之前，但后续历史研究不再需要临时拼接下载流程。新的开发源同步器已经按固定协议绑定：只读取 Tushare `limit_list_d` 的 `ts_code,trade_date,limit,last_time,open_times`，覆盖 2019–2023 共 1,214 个接受的本地交易会话，并按当日有效的可买池区间生成会话分区。它不读取日线价格、比较因子、前瞻收益或 2024–2025 压力区间。

同步器采用单线程顺序请求和至少 1.05 秒的本地间隔。整体意图在加载凭据前持久化，每个会话的请求意图在调用数据商前持久化；只有完整、连续、逐字节复核的 checkpoint 前缀可以续跑。若请求意图已存在但 checkpoint 不存在，状态被视为可能已经进入数据商调用，禁止重试。每个会话目录、内部清单、最终根和仓库清单均采用原子发布；最终根已完整但仓库清单尚未发布时，只允许零网络本地收尾。

9 项开发同步器定向测试通过，包含精确日历、点时有效股票池、前缀续跑、中断禁重试、未知分区拒绝、两会话原子成功、数据商失败闭合、缺少显式授权参数时零写入，以及符号链接锁拒绝。纳入 Campaign113–115 相关测试后的联合回归为 86 项全部通过；Black 与 Ruff 检查通过。真实开发 plan 返回退出码 2，完整识别 1,214 个待同步会话，运行时指纹有效，且凭据加载和数据商请求均为 false。

当前两个 blocker 是：用户尚未明确确认当前配置账户已经具备至少 5,000 积分，以及固定日期的一次性来源验收尚未成功提交。仓库 `.env` 仅验证为存在、0600、包含一个非空受支持 Token 配置；Token 内容没有打印、哈希、记录或持久化。真实验收取证仍是 `no_attempt_journal`，开发锁、partial root、final root、成功清单和失败清单均不存在。

本轮追加式台账记录了四次开发实现/验证基础设施失败以及一次随后发生的取证包装断言失败；它们均未读取研究值或调用数据商。Campaign115 当前累计 11 次尝试，其中基础设施失败 9、预值科学尝试 2、完整因子尝试 0、收益读取试验 0；全部历史研究累计尝试 864，收益读取试验仍为 302。141 个完整定义和 134 个数值比较器的顺序未变，Candidate49 的信号与执行台账哈希未变，也没有启动 Candidate50、回填历史结果或生成当前评分、选股、仓位或订单。
