# A 股三日短线历史滚动研究：Campaign081

Campaign081 已终止，结论是“不存活”。候选因子 `intraday_amount_path_efficiency_238p` 固定为高方向：对精确 240 根连续竞价成交额做 `log1p`，分别计算上午和下午的绝对端点位移与总绝对变差，再用两段端点位移之和除以两段变差之和；午间休市不连接。

## 无收益门

因子快照覆盖 33,015 个分区、7,724,498 个股票日，全部通过逐文件字节和帧哈希验证。冻结质量/上市样本中的中位覆盖率为 99.9452%，5% 分位覆盖率为 99.5689%，可形成 540 个不重叠三日 cohort。

覆盖门通过后才加载 110 个冻结数值比较因子。110/110 均通过，最高绝对中位日截面秩相关为 0.4844，对应 `intraday_market_amount_profile_synchronization_240m`，低于 0.8 的严格门槛。因此该因子获准进入唯一开发试验。

## 2019–2023 开发结果

三组验证折的平均 Rank IC 全部为负：

- 2021：−0.0416；标准化组合收益 +20.54%；20 万元、10bp 试算收益 +0.14%。
- 2022：−0.0302；标准化组合收益 −44.16%；10bp 试算收益 −6.10%。
- 2023：−0.0402；标准化组合收益 −52.06%；10bp 试算收益 −10.06%。

开发全期平均 Rank IC 为 −0.0282，10bp 试算累计收益为 −16.21%，20bp 为 −23.07%。第二、三折整手可负担率分别为 89.95% 和 89.64%，低于 90% 门槛；中位验证 IC、价差、试算收益以及最差验证回撤也均未过门。验证质量门和执行门同时失败，开发存活数为 0。

## 终止与边界

2024–2025 压力收益未打开；不得把高方向失败改成低方向重跑，也不得改 `log1p`、端点或变差定义、连接午间、改用单半日、筛年份、加过滤、再拟合或与旧终止因子组合救援。该历史结果不能生成当前评分、选股、仓位、订单或投资建议。

Candidate49 仍是唯一活动的前瞻候选；其信号和执行账本保持 0 条，Campaign081 没有历史回填、没有供应商请求，也没有启动第二个前瞻候选。
