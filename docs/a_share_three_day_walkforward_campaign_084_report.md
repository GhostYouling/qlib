# A 股三日历史滚动 Campaign084 报告

Campaign084 只研究一个事前冻结的 higher 候选：`quarterly_profit_growth_level_acceleration_floor_2r`。在严格点时可用且共同有限的股票日横截面上，分别对当期 `profit_yoy` 水平和同股票同财报季度的 `profit_yoy` 同比一阶变化计算 average-tie 百分位排名，最终固定取两项排名的较小值。经济含义是利润同比增长必须同时处于较高水平且仍在加速，较弱的一项决定得分。没有搜索方向、权重、算子、阈值、过滤、子集、年份、成本、模型或额外组合。

## 实现与快照

完整语义库 115 项、数值比较库 113 项以及单一公式在候选源值前冻结。特征只读取季度源的 `instrument/report_date/announcement_date/profit_yoy` 和 clean stock-day identity 的 `trade_date/symbol/provider`；没有读取比较值、日线价格或 forward return，也没有发起 provider 请求。

不可变快照包含 33,015 个分区、7,724,498 行，其中 6,321,289 行具有技术有限值；manifest SHA256 为 `68a547c9d85f6437382a16704f601074264c8206dd5fe4d23adaff20079f5994`，dataset SHA256 为 `eaae6e206284f605e6d673a89166ab996e4f246d59955f4d8f427ff7d8aecc5a`。所有分区字节、frame、资格行数和聚合哈希均通过独立验证。首版绑定只在手工展示有效行比例时写错小数，v2 以精确的 `6321289/7724498 = 0.8183430172420266` 追加纠正；快照和门禁未改变。

## 无收益门禁结果

在冻结质量/当前上市资格宇宙的 1,331,759 行和 1,632 个日历交易日上，候选有效行为 1,112,914。逐日覆盖中位数为 `99.459396%`，但 P05 覆盖率和 P05 可用股票数均为 `0`，低于冻结的 `90%` 和 50；潜在非重叠三会话 cohort 为 458，观察年份为 2020–2025。

失败来自定义的结构性冷启动：同财报季度加速度需要上一年同季度的 `profit_yoy` 基准，因此 2019 年早期无法形成候选状态。稳定期覆盖很高不改变事前冻结的全历史 P05 门禁。覆盖失败后 113 个比较器值一个都没有读取，2019–2023 开发折、日线价格和 forward return 没有打开，2024–2025 压力区间也没有打开。

这不是收益失败结论，也不授权删除 2019、放宽 P05、改成单独利润同比水平、改变加速度口径、重标、反向、过滤、残差化或以同轮变体救援。Campaign084 定义永久保留在完整语义库中。只读复核显示该不可变快照在 2020-04-29 至 2025-12-31 有 1,378 个交易日至少 50 只候选股票，因此按既有 Campaign070 先例，它仍是下一轮数值重复检测的有效比较器；覆盖失败本身保持不变。

## 研究边界与计数

本轮最终保留 11 次基础设施失败和 1 个完整因子尝试。除运行时入口与绑定摘要字段失败外，终态组合验证保留 Black、Ruff 和两条冻结生命周期前态断言对应的三条失败命令；更新终态测试的绑定路径后，第一次 Black check 又在测试前要求机械换行，计为第 11 次失败。冻结脚本和旧测试均未改写，精确排除两条前态断言后的组合套件为 13 passed、2 deselected；格式化后的最终终态测试为 4 passed，Black/Ruff 均通过。所有失败均未改数据或读取收益。累计历史研究尝试由 533 推进到 545，累计读取开发收益的试验仍为 284。

Candidate49 仍是唯一前瞻候选，信号与执行台账各 0 条；没有历史收益、信号或执行回填，没有启动第二个前瞻候选，也没有生成当前评分、选股、仓位、订单或投资建议。当前上市快照存在幸存者偏差，季度快照可能存在修订偏差；本结果不是纯净样本外证据，也不是投资建议。
