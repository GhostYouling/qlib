# A 股三日短线 Campaign105 研究报告

Campaign105 已完成并终止：`intraday_active_trading_bar_share_240m` 通过覆盖与 131 项无收益数值去重门，但唯一的 2019–2023 三折开发试验没有通过冻结存活门槛。survivor 为 0，因此 2024–2025 准样本外压力区间保持关闭、未读取。

## 因子定义

对 09:31–11:30、13:01–15:00 的精确 240 根标准一分钟 bar，要求每根 `volume`、`amount` 有限且非负，并满足精确零等价：`volume == 0` 当且仅当 `amount == 0`。两者同时为零是有效“不活跃”bar，两者同时严格为正是“活跃”bar，单边为零使整个股票日缺失。因子值为活跃 bar 数除以 240，方向为 higher。09:30 不参与；不使用价格、活跃幅度、顺序、旧因子值或收益，也不搜索窗口、阈值、方向、过滤、子集、权重、模型或组合。
