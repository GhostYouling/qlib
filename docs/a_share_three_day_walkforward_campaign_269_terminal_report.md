# Campaign269：发行人设施外生灾害概念前沿

Campaign269 完成了一轮零网络、概念级的有限侦察。Campaign264 已确认本地日线与一分钟 OHLCV/成交额没有未消费的独立原始通道；Campaign157 的可转债、ETF 一级市场、发行人信用利差和期权曲面目录也已分别进入 Campaign265–268。继续在这些字段上换统计量、窗口、阈值或组合，只会制造结果暴露后的“新因子”。

本轮转向一个仓库尚未接纳的外部状态：发行人设施所遭遇的物理或政策灾害。有限目录共 6 条，全部在公式和值之前记录：设施极端降水/洪涝、极端冷热、台风风雨、地震地面运动、空气污染应急限产和公共卫生移动限制。唯一保留给下一阶段来源合同的是 `c269_01 issuer_facility_extreme_precipitation_or_flood_exposure`。它不是因子，没有方向、公式、字段、阈值或窗口，也没有授权读取来源。

这条路线与既有环境会计、处罚、事故披露和市场因子在经济状态上不同：它要求外部观测先发生，再通过点时有效的法律实体—子公司—设施映射归属到发行人。仓库有终止的发行人环境指标、事故披露和执法事件，但没有被接受的 2019–2023 设施历史、坐标及运营区间、灾害网格或站点版本、空间连接、修订链和全发行人零暴露分母。因此本轮只证明“值得单独做来源合同”，不证明来源可用或有预测性。

冷热和台风路线因会在基础设施合同尚未接受时引入灾害类型、阈值、半径、持续时间和方向搜索而拒绝；地震和空气污染应急限产保留为未选中的独立来源延期，不得在本轮扩张；公共卫生限制因 2019–2023 特殊制度样本、政策分类和设施映射不可识别而拒绝。

Campaign269 共记录 17 次尝试：6 次值前科学路线和 11 次基础设施失败。前 5 次失败包括两次技能长输出截断、一次错误的 Candidate49 账本路径只读探测、一次宽范围来源盘点截断和一次合并报告长尾读取截断；终态阶段另有一次补丁上下文失配、一次从非 Git 工作区入口执行只读状态检查，以及一次将哈希与过宽历史文本检索合并后输出截断。首次跨阶段回归因 `--deselect` 参数形式没有排除 4 个旧统一报告哈希节点而非零退出；第二次虽改用等号，但仍误把 pytest 根目录下的 node ID 写成仓库相对路径，继续命中同 4 个旧节点。两次非零验证结果全部作废；随后只读收集确认实际 node ID 从 `data_collector_tests/` 起始。首次混合暂存命令又因 `data/` 忽略规则退出 1，虽已暂存其他文件但尚未提交；该过程没有改变研究值。累计历史研究尝试为 2,720，累计收益读取开发试验仍为 315。

本轮没有创建完整因子或数值比较器，库保持 `162/143`；没有读取来源行、候选值、比较值、日线价格、forward return 或 2024–2025 压力收益，也没有请求 provider 或 Web。Campaign265 不变。Candidate49 的 2026-08-24 同日来源运行已在此前因 `stock_basic_invalid_ts_code` 失败封口，本轮未重试；信号和执行账本保持 0/0。

下一轮 Campaign270 只允许为 c269_01 做一份独立的零行来源合同：在任何行之前冻结发行人/子公司/设施身份与运营区间、灾害来源及修订、公开时间、空间连接、零暴露分母、完整 2019–2023 覆盖、缺失语义、最终公式和方向。如果合同闭合不了，应在来源门终止，不得改试冷热、台风、半径、阈值或窗口。历史研究结果不构成投资建议，也不授权当前评分、选股、仓位或订单。
