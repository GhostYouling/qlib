# Campaign267：发行人债券信用利差—股票背离来源值前终止

Campaign267 只重访 Campaign157 的 c157_02，并在任何来源行、候选值、比较器、证券价格或收益值打开之前完成有限来源审计。结论是来源合同终止，不是因子预测失败：当前授权与已审官方元数据无法同时证明通用发行人债券的可执行清洁收益率、期限匹配基准、点时发行人—A 股映射、多债聚合和无存续偏差的 2019–2023 完整分母。

## 有限路线

共冻结 7 条路线：精确发行人清洁收益率减匹配曲线、OTC 报价收益率代理、交易所债券大宗交易代理、可转债纯债价值/溢价替代、评级类别曲线映射到股票、当前中债估值或当前存续名单历史回填，以及基于已观测债券的子集/滞后/期限/聚合/模型搜索。7 条全部值前拒绝，公式和方向保持空；没有选中因子、快照、适配器、来源请求、比较值、开发试验或 2024–2025 压力试验。

Tushare 的 `bc_otcqt`/`bc_bestotcqt` 在 2000 积分级可见债券报价与到期收益率，但公开 schema 不包含完整的法律发行人—A 股版本映射、无债发行人分母、2019–2023 完整覆盖证明或固定的陈旧/多报价处理。`bond_blk` 要求 5000 积分且仅是稀疏大宗交易价格；`yc_cb` 是需独立权限的国债曲线；`repo_daily` 是回购利率。`cb_basic`、`cb_daily`、`cb_rating` 只覆盖可转债，其中估值与溢价包含转股期权语义，且该来源族已经由 Campaign265 独立冻结，不能重贴为通用信用利差。

ChinaMoney/CFETS 的收盘曲线是政府、政策行或评级/类别曲线，不是发行人特定的可执行收益率。中债当前估值查询页展示当前债券代码、场所、剩余期限、净价/全价、收益率和隐含评级，但本轮审阅的公开页面没有形成可验证的 2019–2023 不可变批量历史、首次公开/修订时钟、版本化股票映射与完整历史分母合同。不得先读取稀疏债券值，再选择有数据的发行人。
