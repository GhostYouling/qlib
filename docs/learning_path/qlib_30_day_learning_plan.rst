============================
Qlib 30 天学习路径
============================

适用对象
========

这份学习路径适合以下背景的使用者：

- 有股票交易经验，理解仓位、换手、滑点、交易成本、回撤和基准
- 有前后端开发经验，能接受工程化配置、模块化抽象和实验管理
- 有 YOLO 或大模型训练经验，熟悉 ``dataset -> train -> validate -> infer -> experiment tracking`` 这类工作流

这不是面向零基础的启蒙路线，而是面向已经有工程能力和市场常识、准备系统学习量化研究的人。


学习目标
========

30 天结束后，目标不是“把所有组件都看完”，而是完成一个最小可复用的研究闭环：

- 能看懂 ``Qlib`` 的核心抽象：``DataHandler``、``Dataset``、``Model``、``Record``、``Strategy``
- 能独立跑通一次 ``qrun`` 工作流
- 能解释回测中最关键的真实性约束：标签、时间切分、股票池、成本和未来函数
- 能基于官方样例改出自己的最小研究方案
- 能产出一份自己的 baseline 结果和改进方向


使用原则
========

先立三条规则，后面 30 天都按这三条执行：

- 先建立正确 baseline，再尝试复杂模型
- 每周都要有可复现输出，而不是只“看懂一点”
- 任何结果先排查数据和回测定义，再讨论模型能力

建议时间投入：

- 工作日每天 1 到 1.5 小时
- 周末每天 2 到 4 小时

第 1 周：跑通最小研究闭环

本周目标

本周交付物
==========

- 一份本地环境说明
- 一次成功的 ``qrun`` 运行记录
- 一份 300 到 500 字的研究流程总结

输出：

输出：

Day 7
-----

- 回顾本周内容
- 不新增任何模型和因子，只复盘“最小研究闭环”

输出：

适合你背景的进阶顺序
====================

考虑到你已经有交易经验、开发经验和机器学习背景，建议按下面顺序进阶：

1. ``LightGBM / Linear`` 打通研究闭环
2. 自定义标签和自定义因子
3. 增加更复杂的表格模型或时序模型
4. 做滚动训练和更严格的 out-of-sample 验证
5. 再考虑组合优化、高频执行或更复杂的深度模型

不建议的顺序：

1. 一开始就上 Transformer、RL 或 LLM 驱动选股
2. baseline 还没解释清楚就频繁换模型
3. 还没控制未来函数和交易成本就讨论收益率


每周自检问题
============

每周结束都重新回答下面 8 个问题：

- 我到底在预测什么
- 这个标签是否和调仓频率一致
- 特征在信号产生时点是否真实可得
- 时间切分是否严格
- 股票池是否历史可见
- 回测成交假设是否可信
- 扣费后结果是否还有意义
- 收益是否只是某种风格暴露


30 天后你应该怎么继续
======================

如果这 30 天执行完成，下一阶段建议只选一条主线：

- 因子研究主线：沉淀因子库、标签库、检验方法
- 模型研究主线：做更严格的模型比较和滚动验证
- 组合主线：加强风险约束、行业约束和收益归因
- 执行主线：往高频、嵌套执行或实盘桥接靠近

如果主线没有选定，不要急着扩展模型复杂度。先让 baseline 可复现、可解释、可审查。
