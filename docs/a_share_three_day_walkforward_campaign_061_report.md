# A 股三日短线历史滚动研究：Campaign061

Campaign061 已完成唯一冻结试验。无收益覆盖和 92 项唯一性比较全部通过，但 2019–2023 三折开发期没有产生存活者，因此 2024–2025 压力区间保持封闭。

## 冻结因子

- 名称：`intraday_day_over_day_realized_variance_stability_238b`
- 方向：越高越好
- 信号：对交易日 `t` 与接受日历中紧邻的 `t-1`，分别构造上午 119 个、下午 119 个一分钟对数收盘收益；每个会话的实现方差是 238 个收益平方和，因子为 `2×min(RV_t,RV_t-1)/(RV_t+RV_t-1)`。
- 有效性：两日实现方差都必须严格为正且有限，不使用 epsilon；不得跨越停牌或缺失股票交易日。
- 时间边界：排除 09:30、午休跨越和隔夜收益。

经济解释是：连续两个交易日的日内波动尺度稳定，可能代表持续的信息与流动性状态。历史结果并未证明它可交易。

冻结划分为 2019–2020→2021、2019–2021→2022、2019–2022→2023；边界清除三个信号会话，并要求 `t/t+1/t+3` 留在同一分区。

- 归一化累计收益：−17.240067% / −2.293530% / −24.769728%。
- 20 万元、100 股整手、买卖各 10bp 收益：−2.780860% / −2.120424% / −4.798731%。
