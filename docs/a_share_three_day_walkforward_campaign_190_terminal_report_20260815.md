# Campaign190 临床试验证据生命周期来源前沿值前终止

Campaign190 固定审查 7 条临床试验路线。试验设计/分期/随机对照与终点、筛选/入组/随机/留存和脱落、数据库锁定/主要次要终点/效应与统计读出，以及不良事件/严重事件/因果性/暂停和恢复，是 4 个不同的临床证据状态；本地缺少完整点时注册、方案、统计分析计划、结果和监管来源，无法冻结申办方/药物/适应症/试验身份、修订与首次公开时间、分析人群和 2019–2023 完整覆盖，因此只记为来源准入延期，不宣称因子无效。

把审批、专利、研发费用、普通事故、质量 KPI 或证券价格改名为临床证据，在来源准入前选择试验期、终点、适应症、人群、阈值、窗口或成功子集，以及组合未准入状态的 3 条路线在值前关闭。不得从最新注册表或论文向历史回填，也不得只保留成功试验。

本轮没有读取试验来源值、因子、比较器、证券价格或收益；没有形成公式、新定义或数值比较器。2024–2025 仍关闭，Candidate49 空账本未变。终局过程中 8 次基础设施失败（一次 Ruff 导入格式失败、三次零写入补丁上下文不匹配、一次工具输出截断、一次过期统一报告路径检索失败、一次假定本地虚拟环境不存在和一次假定 Anaconda Git 路径不存在）均已追加记录并恢复，没有作为科学证据。最终会计为 7 次科学尝试、8 次基础设施失败，共 15 次，累计历史尝试 `1685`，收益读取仍为 `314`，定义/比较器保持 `158/142`。
