# A 股三日短线历史滚动研究：Campaign080

Campaign080 已终止，结论是“不存活”。候选因子 `intraday_above_median_amount_longest_run_240m` 固定为高方向：在精确 240 根连续竞价成交额中，以全日普通中位数划分高活跃状态，分别计算上午、下午最长连续高状态，取两者较大值除以 120；午间休市不连接。

## 无收益门

因子快照覆盖 33,015 个分区、7,724,498 个股票日，全部通过逐文件字节和帧哈希验证。冻结质量/上市样本中的中位覆盖率为 99.9452%，5% 分位覆盖率为 99.5689%，可形成 540 个不重叠三日 cohort。

覆盖门通过后才加载 109 个冻结数值比较因子。109/109 均通过，最高绝对中位日截面秩相关为 0.5121，对应 `intraday_amount_center_of_mass_240m`，低于 0.8 的严格门槛。因此该因子获准进入唯一开发试验。

## 2019–2023 开发结果

三组验证折的平均 Rank IC 全部为负：

- 2021：−0.0341；标准化组合收益 +49.91%；20 万元、10bp 试算收益 +6.04%。
- 2022：−0.0378；标准化组合收益 −25.26%；10bp 试算收益 −6.77%。
- 2023：−0.0479；标准化组合收益 −15.82%；10bp 试算收益 −2.35%。

开发全期平均 Rank IC 为 −0.0297，10bp 试算累计收益为 −9.90%，20bp 为 −17.58%。三折整手可负担率分别为 87.78%、84.02%、85.39%，均低于 90% 门槛。验证质量门和执行门同时失败，开发存活数为 0。

## 终止与边界

2024–2025 压力收益未打开；不得把高方向失败改成低方向重跑，也不得改分位数、连接午间、改变 tie 规则、筛年份、加过滤、再拟合或与旧终止因子组合救援。该历史结果不能生成当前评分、选股、仓位、订单或投资建议。

Candidate49 仍是唯一活动的前瞻候选；其信号和执行账本保持 0 条，Campaign080 没有历史回填、没有供应商请求，也没有启动 Candidate50。
