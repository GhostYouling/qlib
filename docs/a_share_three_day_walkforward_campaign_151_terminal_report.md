# Campaign151 零覆盖终止报告

Campaign151 唯一冻结的 higher 因子是 `intraday_relative_amount_share_clock_center_240m`。它在 240 个连续交易分钟上用个股原始成交额除以同钟点、剔除自身后的完整同行平均成交额，再把 240 个相对成交额比值归一化并计算时钟重心。公式、方向、分钟网格、至少 50 个同行以及“每个同行钟点均值必须严格为正”的门槛都在读取历史值前冻结。

来源绑定构建器先因合法的零行清洗分区失败，窄修复只允许该分区返回空贡献；恢复后原子发布 33,015 个分区、7,724,498 行、5,396 个标的和 1,699 个交易日。独立 verifier 又在候选分区读取前暴露一次 tuple 比较实现失败，修复并重新冻结后，全量验证通过全部分区 byte/frame 哈希、sidecar、键排序与唯一性、聚合 dataset digest。
