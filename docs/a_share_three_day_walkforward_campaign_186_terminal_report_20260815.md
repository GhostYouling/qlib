# Campaign186 航运船队与租船履约来源前沿值前终止

Campaign186 在读值前冻结了 7 条航运船队、造船订单、租船覆盖、停租维修与船舶处置路线。自有/受控船队和新造船订单交付、租入租出合同覆盖/费率/期权/交易对手、利用率/停租/坞修/维修与合规可用性，以及船舶购售/减值/收回/回收拆解 4 类发行人状态，因为缺少完整点时船舶与合同来源而延期；它们没有被判定为无效。

把租赁、固定资产、资本开支、运价、利用率 KPI、普通合同或证券价格改名为船队质量，在基础来源准入前搜索船队规模/船龄/租金/覆盖率/利用率/分母/窗口/船型子集，以及组合未准入组件的 3 条路线在读值前关闭。不得从当前船队表或最新订单簿向历史回填，也不得只保留成功交付、持续在租或盈利处置船舶。

本轮没有读取船舶、订单、租约、停租、坞修或处置来源行，未读取因子值、比较器、证券价格或收益；没有形成公式、新定义或数值比较器。2024–2025 仍关闭，Candidate49 仍是唯一前瞻候选且两个空账本未变；周六没有读取凭据存在性、发出网络请求或运行日更工作流。
