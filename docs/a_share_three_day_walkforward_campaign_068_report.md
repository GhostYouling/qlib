# A 股三日历史滚动 Campaign068 报告

Campaign068 只研究一个事前冻结候选：`quarterly_profit_revenue_acceleration_rank_gap_2r`，方向为 higher。它分别计算 `profit_yoy` 与 `revenue_yoy` 在同一股票、同一财报月份上的同比一阶变化，在公告日后的首个接受交易日生效并独立前向传播；随后在每日共同有限值横截面上做 average-tie 百分位排名，固定计算“利润同比加速度排名减收入同比加速度排名”。没有搜索权重、组件、算子、阈值、过滤器、窗口、年份、成本、模型或组合。

## 实现与快照

首个 v1 快照生成了 33,015 个分区、7,724,498 行和 6,317,276 个合格值，但继承验证器误用 `[0,1]` 值域拒绝了合法负值。该失败已作为一次基础设施尝试记录；v1 快照未被接受或复用。追加式 v2 只修复验证值域为冻结的 `[-1,1]`，重新从源构建全部分区，并通过字节、frame、资格、值域、总行数及 dataset hash 的独立全量验证。

v2 snapshot manifest SHA256 为 `9878e6c0249cb9e965dbfade2ce2b3a355bed5e6a46bf68667c82fc568672004`，dataset SHA256 为 `bcd03a5e2122b64b072985b3a9a9ada880cad337dae4766a00cf52bf51f4f449`。

## 无收益门禁结果

在冻结质量/上市资格宇宙的 1,331,759 行、1,632 个交易日上，候选有效行为 1,112,691。逐日覆盖中位数为 `99.459396%`，但 P05 覆盖率和 P05 合格名称数均为 `0`，低于冻结的 `90%` 与 50 门槛；潜在非重叠三会话 cohort 为 458，观察年份为 2020–2025。

失败来自定义的结构性冷启动：同季度一阶差分至少需要上一年同报告月份，因此 2019 年初无法形成候选状态。稳定期覆盖很高不改变事前冻结的 P05 门禁，Campaign068 因此终止，不允许删去 2019、放松覆盖门槛、改成普通同比水平、回填历史状态或以同轮变体救援。

## 研究边界与计数

覆盖失败后没有读取 compact cache 的 98 个比较因子值，没有读取日线价格或未来收益，没有打开 2019–2023 开发试验，也没有打开 2024–2025 压力区间。Campaign068 计入一次基础设施失败和一次完整因子尝试，使累计历史研究尝试从 402 增至 404；累计读取开发收益的试验仍为 274。

Candidate49 信号与执行台账未变，没有历史收益、信号或执行回填，没有启动第二个前瞻候选，也没有生成当前评分、选股、仓位或订单。当前上市快照仍存在幸存者偏差限制；本结果不是投资建议。
