# Campaign115：开发源同步与本地语义验真路径均已预建

Campaign115 仍停留在任何真实数据商取值之前，但 2019–2023 历史研究的数据准备链已经预建到“不可变语义指纹”这一层。开发源同步器只读取 Tushare `limit_list_d` 的 `ts_code,trade_date,limit,last_time,open_times`，覆盖 1,214 个接受的本地交易会话，并按当日有效的可买池区间生成会话分区；新的本地语义验真器则在完整开发源到齐后逐会话复核这些分区。两者都不读取日线价格、比较因子、前瞻收益或 2024–2025 压力区间。

验真器不是只信任 checkpoint 的字节哈希。它还要求最终根、请求意图、会话目录和文件严格符合白名单；重新验证全部 checkpoint、请求意图、点时有效股票池顺序、列顺序、交易日期、`tushare` 来源字面值、布尔事件标记、因子 `[0,1]` 范围、非事件严格为零、事件数与 checkpoint 一致、单会话来源行数低于 5,000，以及内部清单和仓库清单逐字节一致。随后它重算每个会话的语义帧哈希和全数据集哈希，但收据不嵌入个股因子值。

这一阶段只有三个固定入口：零值读取的 `plan`、需要 `--confirm-semantic-verification` 的本地验真发布，以及只读收据检查。没有可传入的替代源根、清单或输出路径，也没有网络或凭据参数。收据使用 0600 私有、独占、原子发布；已有收据绝不覆盖。它最多只能作为后续另行冻结的有序无收益审计输入，不能授权收益回测、2024–2025、当前评分、选股、仓位或订单。

首次合成套件为 6 通过、1 失败：两会话合成源完成语义检查后，收据构造器错误地要求 monkeypatch 到系统临时目录的合成源清单仍必须是仓库相对路径。该命令没有发布收据，也没有读取任何真实历史值。失败已单独记录并计数一次；v4 窄修复保持真实绑定清单使用仓库相对路径，仅允许显式替换的合成路径使用绝对展示。相同参数重试为 7/7 通过，覆盖 plan 不读 Parquet、完整深验与私有收据、显式确认、禁止第二次发布、非事件非零篡改拒绝、未知会话文件拒绝，以及缺失/畸形收据只读取证。

真实语义验真 `plan` 返回退出码 2，阻塞项严格为最终开发源根、内部源清单、仓库源清单和两份清单逐字节一致性尚不存在。`parquet_candidate_values_read=false`、`credential_loaded=false`、`provider_request_issued=false`；收据检查返回 `no_semantic_verification_receipt`。这不是科学失败，只说明 1,214 会话来源尚未获得。

来源获取仍受原有两个前置条件约束：用户尚未明确确认当前配置账户已经具备至少 5,000 积分，以及固定日期的一次性来源验收尚未成功提交。仓库 `.env` 只验证存在性、0600、Git 忽略和一个非空受支持 Token 配置；Token 内容不会打印、哈希、记录或持久化。Token 存在不等于积分资格，不能代替用户确认，也不能通过试探 API 猜测权限。

Campaign115 当前累计 12 次尝试，其中基础设施失败 10、预值科学尝试 2、完整因子尝试 0、收益读取试验 0；全部历史研究累计尝试 865，收益读取试验仍为 302。141 个完整定义和 134 个数值比较器的顺序未变，2024–2025 未打开，Candidate49 的信号与执行台账哈希未变，也没有启动 Candidate50、回填 Candidate49 历史结果或生成当前评分、选股、仓位、订单和投资建议。
