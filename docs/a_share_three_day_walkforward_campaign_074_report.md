# A 股三日短线 Campaign074 研究报告

Campaign074 已完成并终止：`intraday_terminal_bar_amount_share_240m` 通过覆盖率和全部 104 项冻结数值唯一性门禁，但唯一一次 2019–2023 扩展式 walk-forward 开发试验没有产生 survivor。2024–2025 压力区间保持关闭且未读取。

## 冻结因子

- 方向：higher。
- 公式：原始会话须存在 09:30 行并具备精确的 09:31–11:30、13:01–15:00 共 240 根标准分钟 bar；分子为精确 15:00 的非负有限 `amount`，分母为这 240 根标准 bar 的非负有限 `amount` 正和。09:30 不进入分母。
- 机制：衡量最后一个标准一分钟 bar 在全天连续交易金额中的集中度，假设尾盘关注与流动性需求可能延续到次日开盘至第三日收盘。
- 本因子不声称使用专用收盘集合竞价逐笔或委托数据，也不等价于集合竞价不平衡因子。
- 没有搜索方向、权重、窗口、过滤、阈值、子集、模型、成本或年份。
