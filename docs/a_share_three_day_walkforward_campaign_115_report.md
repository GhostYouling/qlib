# Campaign115：官方涨停队列持久性（值前阶段）

Campaign115 没有继续排列已经暴露的分钟 OHLCV/amount 算子，也没有再次拟合 134 个终止比较器。有限概念审计选择了一个新的逐时点信息通道：Tushare `limit_list_d` 官方涨停事件中，最后封板时刻与开板次数共同描述的收盘买单队列持久性。它与旧日线“涨停样强势收盘”不同：后者只能从收盘收益和距日高位置推断，不能恢复官方事件类别、最后封板时刻或开板次数。

唯一公式已经在任何供应商行之前冻结：有效 `U` 事件取 `收盘前剩余交易分钟 / (245 × (1 + 开板次数))`，有效 `D`、`Z` 以及完整非截断事件表中未出现的点时可买股票均为 0，高值方向固定为更好。不得改用首次封板、封单金额、市值、换手、价格、收益或旧因子；不得反向、换类别映射、换日期、挑事件密集时期或补做模型组合。

本轮只实现了不含网络、凭据或供应商 SDK 的纯适配器。合同 CLI、Ruff、Black 和 15 项定向测试已通过，覆盖合同指纹、精确字段顺序、5000 行截断门、股票日去重、U/D/Z、午休时间轴、无事件补零和非法时刻/开板次数。尚未执行 Tushare 请求，未读取候选值、比较值、日线或 forward return；2019–2023 三折 walk-forward 和 2024–2025 准样本外均未打开。

Campaign115 当前不是通过的因子，也不是投资建议。下一步先冻结一次性验收 runner、失败记录路径、代码/测试指纹和安全 `.env` 门禁；只有这些全部通过，才能对固定的 2026-07-13 发出一次 `limit_list_d` 权限/模式请求。随后仍需完整 2019–2023 原子来源、200 个三日 cohort、全 134 比较器唯一性以及现有次日开盘不可成交拦截全部通过，才允许读取开发收益。Candidate49 继续是唯一前瞻候选，两本前瞻账本保持为空。
